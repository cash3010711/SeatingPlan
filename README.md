# 囍 婚禮座位安排與現場報到系統 (Wedding Seating & Reception WebApp)

> 一套專為新人與婚禮接待團隊打造的現代化婚宴排座與即時報到系統。具備 2D 畫布佈局、看板拖曳、家庭群組佔位席、Excel 智慧防呆匯入、/usher 現場行動招待台、/lookup 賓客自查桌號與飯店會館交接總表匯出等全方位功能。

---

## 🌟 核心功能特色

### 1. 2D 互動畫布與幾何會場佈局
- **無段平移與縮放**：支援滑鼠滾輪與觸控手勢（0.4x ~ 2.2x），搭配細緻淡色 Dot Grid 網格與 20px 磁吸對齊開關。
- **桌位實體節點 (Table Nodes)**：圓桌與長桌樣式、自訂桌號與桌名、容量上限（預設 10 人，主桌可調為 12 人）。
- **軟性超額提示 (Soft Excess Alert)**：若排入人數大於容納上限（例如 `11/10`），系統不予阻擋，顯示醒目紅色呼吸燈外框與 `11/10 ⚠️` 警告。
- **正式桌 vs 預備桌 (備桌)**：支援一鍵切換備桌標記，虛線外框呈現，在統計與交接總表中清楚區隔。
- **會場幾何地標 (Landmark Nodes)**：內建主舞台、進場紅毯走道、正門大門、樑柱障礙物、收禮接待桌、音控燈光台，支援自由拖曳、尺寸調整與 90 度旋轉。
- **畫布 PNG 匯出與列印**：支援一鍵將平面排座圖匯出為高畫質 PNG 圖檔，或直接發送 A4 最佳化列印。

### 2. 賓客名單與家庭群組管理 (Household Groups)
- **家庭群組與自動佔位席**：新增家庭時只需輸入總人數，未知姓名成員自動生成虛擬佔位席（如「王大華 眷屬 #1」、「王大華 眷屬 #2」）。
- **整家一鍵帶入某桌**：可整戶一鍵帶入指定桌次，亦可拆解單人細部微調。
- **未指派賓客池抽屜**：右側側邊欄抽屜常駐未排賓客卡片，支援關鍵字即時模糊搜尋與男女方、素食過濾。
- **關係生活圈分類標籤 (Tags)**：支援自由標記標籤（如「大學同學」、「新娘閨蜜」），並提供「同標籤成員一鍵批次指派至某桌」捷徑。
- **雙模式自由切換**：可隨時在「2D 畫布模式」與「看板網格模式 (Board View)」間一鍵切換。

### 3. Excel 智慧整合與同名防呆對照視窗
- **Append 追加匯入**：保證不覆蓋、不刪除現有已排桌位資料。
- **智慧模糊欄位映射**：相容常見別名（姓名/大名/賓客、葷素/飲食習慣、男方/女方、兒童椅/娃娃椅、喜餅盒數等）。
- **重複名單偵測與對照視窗**：偵測到同名重複時以黃色醒目標記，並提供 3 種彈性策略選擇：
  1. **當作同名同姓新增**（不同身分）
  2. **略過此筆不匯入**
  3. **合併更新既有資料**
- **範本下載與報表匯出套件**：
  - 📥 **下載標準 Excel 範本檔** (`.xlsx`)
  - 📊 **飯店會館交接專用總表** (`.xlsx`)：包含各桌桌號、桌名、實到人數、葷食數、全素數、蛋奶素數、兒童餐數、兒童椅張數、特殊飲食備註。
  - 💰 **完整賓客名冊與禮金簿** (`.xlsx`)：包含序號、桌號、姓名、所屬方、餐食、紅包編號、禮金金額、報到狀態。
  - 🎁 **喜餅發放清冊** (`.xlsx`)：包含女方/領餅親友領取盒數、領取狀態與代領人備註。

### 4. 現場招待速查報到台 (`/usher`)
- 專為手機與 iPad 觸控平板介面最佳化，超大字體與高對比色塊。
- **極速搜尋**：輸入字首在 100ms 內即時過濾賓客與其桌號。
- **一鍵報到**：超大按鈕一鍵完成報到與出席統計。
- **喜餅核銷**：女方親友卡片直接顯示「🎁 領取喜餅」，點擊即可完成核銷。
- **收禮台禮金記帳抽屜**：可展開輸入「紅包收據編號」與「禮金金額」，提供快捷金額按鈕（$2000, $2600, $3600, $6600, $12000 等），金額即時更新至禮金總額。
- **連線狀態指示燈**：頂部即時顯示 `🟢 線上同步中` / `🟡 離線暫存模式`，斷網操作自動進入背景佇列，恢復連線後自動上傳寫入。

### 5. 賓客現場自查桌號頁面 (`/lookup`)
- 免登入，具備典雅溫馨的婚宴歡迎封面。
- **嚴格隱私隔離 (Strict Privacy Shield)**：
  - 查詢結果**僅回傳該姓名個人的桌號、桌名與餐食安排**。
  - 前後端均嚴格遮蔽他人個資、聯絡資訊與禮金金額，徹底杜絕資料外洩。
- **迎賓立牌 QR Code 產生器**：主控台一鍵產生並下載高解析度 QR Code 圖檔，供新人印製迎賓水牌放置於會館入口。

### 6. 快照備份與版本還原 (Snapshot Management)
- 支援一鍵將當前全部桌位、賓客、家庭與地標狀態備份為快照。
- 歷史快照清單管理，隨時一鍵還原至指定歷史版本。

## 🛠️ 技術架構

- **前端框架**：React 18 + TypeScript + Vite
- **樣式與圖標**：Tailwind CSS + Lucide React
- **路由系統**：React Router DOM v6
- **試算表處理**：SheetJS (`xlsx`)
- **影像與條碼**：`html-to-image` + `qrcode`
- **資料庫與 Realtime**：`@supabase/supabase-js`
- **離線與容錯機制**：LocalStorage + Offline Queue（無金鑰時無縫降級為純本地全功能模式）
- **單元測試**：Vitest + Testing Library

## 🚀 快速開始

### 1. 安裝相依套件

```bash
npm install
```

### 2. 本地啟動開發伺服器

```bash
npm run dev
```

瀏覽器開啟 `http://localhost:5173`。

### 3. 執行測試套件

```bash
npm test
```

所有單元測試與端對端驗證測試將由 Vitest 執行。

### 4. 正式生產環境編譯

```bash
npm run build
```

編譯產物將輸出至 `dist/` 目錄。

## 🗄️ Supabase 資料庫設定說明

若需開啟多裝置 Realtime 即時連動（例如：多位現場招待同時使用不同手機進行報到）：

### 步驟 1：建立 Supabase 專案
前往 [Supabase 官網](https://supabase.com) 建立專案。

### 步驟 2：在 SQL Editor 執行建表 Script
複製執行 `openspec/specs/data-model.md` 中的 PostgreSQL DDL 程式碼，建立 `tables`, `groups`, `guests`, `landmarks`, `snapshots` 5 張資料表並開啟 Realtime 廣播。

### 步驟 3：設定環境變數
在專案根目錄建立 `.env.local` 檔案：

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

*註：若未建立 `.env.local`，亦可直接點擊系統導覽列右上角的連線圖標，在彈出的「系統與資料庫連線設定」視窗中直接輸入 Project URL 與 Anon Key，系統會自動儲存至 LocalStorage 並立即連線！*

## 📦 部署指南 (Deployment)

### Vercel 一鍵部署
1. 將專案連結至 GitHub 儲存庫。
2. Framework Preset 選擇 **Vite**。
3. （選填）在 Environment Variables 中填入 `VITE_SUPABASE_URL` 與 `VITE_SUPABASE_ANON_KEY`。
4. 點擊 Deploy 即可自動完成建置。

### Netlify 部署
1. Build command: `npm run build`
2. Publish directory: `dist`
3. 新增 `_redirects` 檔案支援 SPA 路由：
   ```
   /*    /index.html   200
   ```
