# OpenSpec: 婚禮座位安排 WebApp (Wedding Seating Planner)

> 版本：1.0.0  
> 建立日期：2026-11-16  
> 狀態：規劃完畢 (Approved & Ready for Implementation)  

---

## 1. 專案目標與願景 (Vision & Goals)

打造一套專為現代婚禮（新人、接待總召、現場招待、宴會業務）設計的高效能互動式座位安排與當日接待系統。  
解決傳統婚宴在 Excel 排座容易重複、家庭眷屬名單不全、無法即時可視化排位、宴客會館兒童椅/素食交接繁雜、以及現場招待翻找紙本名單塞車等痛點。

---

## 2. 角色與使用情境 (User Personas & Scenarios)

| 角色 (Persona) | 使用場景 (Scenario) | 核心需求 |
| :--- | :--- | :--- |
| **新人 (新郎 / 新娘)** | 籌備期 (前 1~3 個月) | 自由新增/移動桌位、匯入 Excel、標記男女方/葷素/喜餅、以家庭群組與圈子標籤批次排座、防呆重複名單。 |
| **宴會總召 / 伴郎伴娘** | 婚禮前夕 (前 1 週) | 檢視預備桌與正式桌、核對兒童餐椅、排解超額衝突、匯出會館主廚交接總表、印製 A4 桌牌與平面圖。 |
| **收禮台接待人員** | 婚宴當天入口 (手機/平板) | 免登入快速搜尋賓客姓名、確認桌號、一鍵勾選報到與喜餅領取、選填禮金編號與金額，支援地下室離線暫存。 |
| **出席賓客** | 婚宴當天門口 | 手機掃描現場立牌 QR Code 自行輸入姓名查詢桌位，免排隊、零個資外洩。 |

## 3. 技術架構 (Technology Stack)

- **前端框架**：React 18 / 19 + TypeScript + Vite
- **造型與圖標**：Tailwind CSS + Lucide React
- **畫布與互動**：
  - 2D Canvas 平面地圖：支援無段平移/縮放 (Pan & Zoom)、桌子與會場地標自由拖曳 (X,Y)、網格吸附 (Snap-to-grid)
  - 拖放操作：HTML5 Drag & Drop / @dnd-kit (看板分桌拖曳、未排賓客池)
- **資料庫與即時同步**：
  - **Supabase (PostgreSQL 15+)**：儲存桌位、賓客、家庭群組、地標與快照版本
  - **Supabase Realtime**：WebSocket 即時訂閱，多裝置雙向同步
  - **本地離線儲存 (Offline Fallback)**：IndexedDB / LocalStorage 快取 + 斷線重連自動同步機制
- **Excel 處理**：`xlsx` (SheetJS) 支援標準範本下載、智慧欄位映射、增量匯入、重複對照表、多格式匯出
- **列印與圖檔**：`html-to-image` / Canvas 匯出 PNG 高解析度平面圖、CSS 專用 Print 樣式

## 4. 路由與存取視圖 (Routing & Views)

1. `/` - **主控排座管理台 (Planner Dashboard)**
   - 包含 2D 畫布模式與看板指派模式切換
   - 頂部全域指標看板 (已排/未排、葷素、男女、兒童椅、喜餅、禮金)
   - 側邊未指派賓客抽屜、Excel 匯入/匯出按鈕、快照備份按鈕
2. `/usher` - **現場招待速查報到台 (Usher Check-in Mode)**
   - 行動端/平板最佳化，大字號搜尋框
   - 一鍵報到開關、一鍵喜餅領取開關、選填禮金記帳
   - 離線快取指示燈（綠燈連線 / 黃燈離線暫存）
3. `/lookup` - **賓客現場掃碼自查頁 (Guest Self-Service Lookup)**
   - 乾淨迎賓畫面，輸入姓名查詢桌位
   - 僅展示該賓客之桌號、桌名、葷素與會場簡圖，嚴格隱藏他人資料與禮金
