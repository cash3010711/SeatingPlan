# OpenSpec: Excel 整合與重複賓客防呆規範 (Excel Integration & Deduplication)

## 1. 欄位自動映射對照字典 (Fuzzy Column Mapping)

當使用者匯入現有 Excel 時，系統以不分大小寫與常見同義字進行自動辨識：

| 系統正規欄位 | 支援的 Excel 欄位別名 | 預設值 (若缺漏) |
| :--- | :--- | :--- |
| **姓名 (name)** | `姓名`, `大名`, `賓客`, `出席者`, `聯絡人`, `Name` | **必要欄位 (缺少則略過該行)** |
| **所屬方 (side)** | `所屬`, `男方/女方`, `類別`, `群組`, `親友`, `Side` | 男方: `groom` / 女方: `bride` (預設 `groom`) |
| **飲食習慣 (meal_type)** | `葷素`, `飲食`, `餐食`, `飲食習慣`, `素食`, `Meal` | 葷: `meat`, 素/全素: `vegan`, 蛋奶素: `vegetarian`, 兒童餐: `kid` (預設 `meat`) |
| **兒童餐椅 (needs_baby_chair)** | `兒童椅`, `兒童座椅`, `娃娃椅`, `Baby Chair` | 包含 "是", "Y", "要", "1" 視為 `true`，其餘 `false` |
| **喜餅盒數 (cake_count)** | `喜餅`, `大餅`, `盒數`, `餅`, `Cake` | 數值（例如 1 或 2，若填「是」預設為 1，其餘 0） |
| **家庭/總人數 (total_count)** | `人數`, `同行人數`, `出席人數`, `大人小孩`, `家庭` | 數值（若 > 1，則自動建立家庭群組與眷屬佔位席） |
| **關係標籤 (category_tag)** | `標籤`, `生活圈`, `關係`, `部門`, `同學會`, `Tag` | 字串（如「大學同學」） |
| **備註 (notes)** | `備註`, `特殊需求`, `過敏`, `Notes`, `Remark` | 字串 |

## 2. 重複資料判斷與預覽對照窗流程 (Deduplication Workflow)

```mermaid
flowchart TD
    A[使用者上傳 Excel 檔案] --> B[前端 SheetJS 解析原始列資料]
    B --> C[欄位智慧對應驗證]
    C --> D[逐筆比對資料庫現有賓客清單]
    
    D --> E{是否出現同名同姓？}
    E -- 否 --> F[標記為全新賓客 (綠色 Normal)]
    E -- 是 --> G[標記為疑似重複 (黃色 Duplicate Warning)]
    
    F --> H[進入匯入預覽與防呆對照視窗]
    G --> H
    
    H --> I[使用者在對照視窗針對重複項目選擇處理策略]
    I --> J1[選項 1: 當作同名同姓新增 (不同身分)]
    I --> J2[選項 2: 略過此筆不匯入]
    I --> J3[選項 3: 合併並更新既有資料]
    
    J1 --> K[執行批次寫入 Supabase (Append-only)]
    J2 --> K
    J3 --> K
    K --> L[跳出匯入成果 Toast: 成功新增 X 人, 略過 Y 人, 合併 Z 人]
```

## 4. 匯出報表規格 (Export Specification)

1. **飯店會館交接專用總表 (.xlsx)**：
   - 欄位：`桌號` | `桌名` | `正式/備桌` | `總席數` | `葷食人數` | `全素人數` | `蛋奶素人數` | `兒童餐數` | `需兒童餐椅張數` | `特殊飲食備註`
2. **完整賓客名冊與禮金簿 (.xlsx)**：
   - 欄位：`桌號` | `桌名` | `姓名` | `所屬` | `飲食` | `兒童椅` | `喜餅領取` | `紅包編號` | `禮金金額` | `報到狀態` | `關係標籤` | `備註`
3. **喜餅發放清冊 (.xlsx)**：
   - 欄位：`姓名/戶名` | `所屬方` | `需發盒數` | `是否已領取` | `代領人/備註`
