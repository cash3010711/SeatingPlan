# OpenSpec: UI/UX 與互動介面規範 (UI/UX Specification)

## 1. 設計語言與色彩計畫 (Design Tokens & Theme)

以典雅浪漫的「當代婚禮風格（Modern Wedding Aesthetics）」為基底，融合喜氣紅色、溫潤香檳金與現代極簡灰白：

- **主色 (Primary)**：`Rose-600` / `Burgundy` (`#E11D48` / `#9F1239`) - 代表婚宴的喜氣與重要操作按鈕。
- **次主色 (Secondary / Accent)**：`Amber-500` / `Gold` (`#F59E0B` / `#D97706`) - 代表主桌、喜餅、精緻徽章標示。
- **男方識別色**：`Blue-500` / `Sky-500` (`#3B82F6`) - 快速辨識男方親友。
- **女方識別色**：`Pink-500` / `Rose-400` (`#EC4899`) - 快速辨識女方親友。
- **葷食標籤**：`Slate-600`
- **素食標籤**：`Emerald-600` (`#059669`) - 醒目綠色，避免宴席上錯菜。
- **背景色**：`Slate-50` / `Stone-100` 乾淨高質感畫布背景，附帶淡色網格點 (Dot grid)。

## 3. 2D 畫布互動細節 (Canvas Interactions)

1. **桌子實體元件 (Table Node)**：
   - 圓桌直徑約 110px，長桌約 140x80px。
   - 頂部顯示桌號（大字號），下方顯示桌名（如「男方大學」）。
   - 中央顯示席次計數 `8/10`，外圈具備環狀填色進度條。
   - 底部顯示小徽章：素食人數（綠點）、兒童椅張數（嬰兒圖標）、喜餅需求（禮物盒圖標）。
   - **超額狀態**：若排入人數 > 容納上限，外框轉為亮紅色呼吸燈，並顯示 `11/10 ⚠️`。
   - **預備桌狀態**：外框改為深灰色虛線，右上角懸掛「備桌」徽章。
   - 點擊桌子展開「該桌賓客明細浮層 (Modal/Popover)」，可檢視每位賓客並支援單擊一鍵移出。

2. **會場地標元件 (Landmark Nodes)**：
   - **舞台**：寬版長方形，深玫瑰金底色，文字標註「主舞台 / 螢幕」。
   - **進場走道**：長條型半透明紅毯區塊，可自訂長度。
   - **大門**：拱門圖示，標記「宴會廳正門入口」。
   - **樑柱**：正方形或圓形深灰障礙物圖塊，標示視線遮蔽區。
   - **收禮台**：長條櫃檯圖塊，標記「男女方收禮處」。

3. **操作輔助**：
   - 支援滑鼠滾輪或觸控板雙指無段平移與縮放（0.3x ~ 2.5x）。
   - 拖曳放開時具備微彈簧動畫，並自動將座標持久化。

## 4. 現場招待速查模式 (`/usher`) 介面特色

- **卡片式超大點擊區域**：手指輕點即完成報到與核銷。
- **醒目高對比狀態顏色**：已報到轉為亮綠色背景，避免日光或昏暗燈光下誤看。
- **喜餅專屬按鈕**：女方親友卡片直接顯示「🎁 領取喜餅 (1盒)」，點擊直接標記已領，已領後變成打勾灰字。
- **禮金小抽屜**：卡片右下方設有「💰 記禮金」折疊按鈕，點開即展開紅包編號與金額快速數字鍵盤輸入。
