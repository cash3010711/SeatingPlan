## 1. 模組 10：一鍵智慧座位編排 (Smart Auto-Seating Engine)

### 1.1 功能規格 (FR-10)
- **FR-10.1 啟動入口**：在系統頂部導覽列提供醒目的「⚡ 一鍵智慧排座」操作按鈕。
- **FR-10.2 智慧分群與家庭不拆散演算法**：
  1. 優先篩選出所有正式桌（非預備桌，排除主桌除非指定，或依桌號遞增排序），計算各桌剩餘可用席位。
  2. **家庭群組優先排座 (Household Integrity)**：針對未排池中帶有 `group_id` 的家庭群組，以戶為單位計算人數，尋找剩餘容量足以容納整戶的桌次排入；絕不拆散家庭成員至不同桌。
  3. **生活圈分類標籤與所屬方聚集 (Clustering by Side & Tag)**：
     - 個別賓客優先依「男方 (groom) / 女方 (bride) / 共同 (mutual)」與「生活圈標籤 (category_tag)」進行分群（例如：男方大學同學、女方至親長輩、高中好友）。
     - 同一分群之賓客依序補入同一桌次，直至該桌達容量上限，再行開啟下一桌次。
  4. **硬性容量防護**：排入過程嚴格以各桌 `capacity` 為上限，不主動製造超額警示。
  5. **執行摘要通知**：排座完成後以 Toast 或輕量提示回報編排結果（如：「已順利為 42 位賓客完成智慧排座！」）。

### 1.2 驗收標準 (AC-10)
- [ ] 點擊「一鍵智慧排座」，未排座位池之家庭群組與獨立賓客自動依照男女方與分類標籤排入合適桌次。
- [ ] 同一家庭群組之所有成員在同一桌內入座，無被拆散情形。
- [ ] 各桌排入人數皆不超過各桌設定之容納上限。

## 2. 模組 11：彈性重置矩陣與預設恢復 (Data Reset Matrix & Restore)

### 2.1 功能規格 (FR-11)
在介面提供三種獨立且語意明確的重置清理選項，每一次執行皆附帶警示與確認防呆機制：
- **FR-11.1 重置目前排座 (Reset Seating Assignments)**：
  - 將所有已排桌賓客全部退回「未排座位池」（即 `table_id = null`）。
  - 保留所有自訂桌位、地標與既有賓客名冊與群組關係不變。
- **FR-11.2 清空桌位與地標 (Clear Venue Layout)**：
  - 刪除畫布上所有桌位與所有會場地標。
  - 完整保留賓客名冊與家庭群組（賓客全員退回未排座位池）。
- **FR-11.3 回復原版預設示範資料 (Restore Default Demo Data)**：
  - 將所有桌位、地標、家庭群組與賓客完整重置回系統初始示範資料（包含主桌、男方至親桌、女方親友桌、舞台與完整示範名冊）。

### 2.2 驗收標準 (AC-11)
- [ ] 執行「重置目前排座」，桌內賓客全數歸零並出現在未排池中，桌子與地標安好保留。
- [ ] 執行「清空桌位與地標」，畫布所有桌子與地標清除乾淨，未排池保留完整賓客名冊。
- [ ] 執行「回復預設示範資料」，系統重現初始展示之主桌、地標與賓客佈局。

## 3. 模組 12：2D 畫布與地標互動體驗增強 (Canvas & Landmark UX Enhancements)

### 3.1 功能規格 (FR-12)
- **FR-12.1 地標選單點擊外部自動收合**：在畫布左下角點擊「+ 新增地標」展開選單後，點擊畫布空白處或其他按鈕時，選單自動偵測並關閉收合。
- **FR-12.2 修復地標旋轉與刪除事件冒泡**：地標懸停工具列上的「旋轉 (Rotate)」與「刪除 (Delete)」按鈕綁定 `onMouseDown` 阻止事件冒泡 (`e.stopPropagation()`)，修復點擊時誤觸畫布或節點拖曳導致功能失效之 Bug。
- **FR-12.3 畫布桌位懸停快捷刪除**：各桌圓形/矩形節點在滑鼠懸停 (Hover) 時，於右上角顯示紅色垃圾桶圖標；點擊後彈出確認對話框即可直接刪除該桌，桌內成員自動退回未排池，無需點入詳情彈窗。
- **FR-12.4 地標文字就地雙擊編輯**：
  - 滑鼠雙擊地標名稱可就地直接進行 Input 編輯修改。
  - 地標懸停工具列增設「✏️ 編輯名稱」按鈕，點擊亦可進入編輯模式。
  - 按 Enter 或失焦 (onBlur) 自動保存最新地標名稱。

### 3.2 驗收標準 (AC-12)
- [ ] 打開地標下拉選單後，點擊畫布任何空白處，選單順利收起。
- [ ] 點擊地標懸停工具列的旋轉按鈕，地標立即順暢旋轉 90 度；點擊垃圾桶確認後立即刪除地標。
- [ ] 滑鼠移至畫布上任一桌子，右上角浮現垃圾桶按鈕，點擊並確認後該桌即被刪除。
- [ ] 雙擊地標或點擊鉛筆按鈕，可直接修改文字並儲存。

## 4. 模組 13：看板模式桌位與家庭群組管理 (Kanban Column & Group Controls)

### 4.1 功能規格 (FR-13)
- **FR-13.1 看板桌位標頭管理工具**：
  - 各桌看板標頭右側提供「編輯設定 (Edit)」與「刪除此桌 (Delete)」按鈕。
  - 點擊編輯可開啟桌位設定彈窗；點擊刪除則確認後移除該桌並將桌內賓客釋放回未排池。
- **FR-13.2 看板桌內家庭群組整合卡片**：
  - 若桌內有屬於同一家庭群組（`group_id`）之成員，以家庭卡片形式整合展示。
  - 提供「整家移出至未排池」與「解散家庭群組」之快捷按鈕。

### 4.2 驗收標準 (AC-13)
- [ ] 在看板模式可直接點擊桌位標頭的齒輪/編輯鈕修改桌號、桌名或人數上限。
- [ ] 在看板模式可直接點擊垃圾桶刪除該桌，桌內賓客即時回到未排座位池。
- [ ] 看板桌內的家庭成員整合顯示，可一鍵將整家退回未排池。
